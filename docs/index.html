Your network has a configuration. You also have a belief about what that configuration should be. Those two quietly stop matching — and nobody notices until something goes down.

driftwatch compares your devices against the config you committed to git, and tells you exactly which lines changed.

How it works

  1. Capture what you intend

    One command reads every device and saves the config as plain text files. You commit them to git, so future changes go through review.

    node src/cli.js pull
git add baseline/ && git commit -m "intended config"

  2. Check, any time

    Run it in the morning, on a schedule, or in CI. It exits 1 if anything drifted, 0 if clean — so anything that understands exit codes can alert on it.

    node src/cli.js check

  3. Look at it, if you want to

    A live dashboard: green when clean, red when not, with the exact lines that changed.

    node src/cli.js serve
Why not Ansible, Salt or Batfish? Those are heavier than most people need, and all of them assume you already have an inventory and a source of truth. driftwatch is one binary, one JSON file, and a directory of text files in git. If you have three devices and a laptop, that is the entire setup.

What it will not do

It never changes a device

driftwatch is read-only. It cannot push, apply or modify anything. It looks and reports, nothing else. A tool that watches your network should not also be able to alter it.

It does not touch your laptop

On this site and in the default demo, the devices are fictional and no SSH connection is opened. Point it at real gear when you actually want to.

It stays on your machine

No accounts, no telemetry, no dashboard service. The dashboard binds 127.0.0.1 by default; exposing it is a deliberate flag.

One more thing it handles for you

Real devices emit noise on every poll — timestamps, uptime counters, byte counts, command echoes. Diff that raw and you learn to ignore the red lines, then stop reading the output. driftwatch strips the noise first, so the report only ever shows real configuration changes.
